How the boards stay fair

  • Best overall ranks each id by its combined z over all its sessions. z already allows for the amount of data: under chance it averages 0 with a spread of about ±1 whether an id has five minutes or fifty hours, while a real, steady effect makes it grow as hours add up. An id needs at least 30 minutes of focus data to qualify.
  • Best single run ranks each id by its best session, corrected for how many sessions it ran: p_adj = 1 − (1 − p_best)^runs, shown back as a z. One great run out of one beats the same run picked from a hundred tries, and starting over with a fresh id does not help much. Runs count from 60 seconds of focus.
  • Effect size (extra hits per 10,000 draws) is shown but never ranked on: over a small amount of data it swings widely, so ranking by it would always favour short lucky sessions.
  • The luck line is the expected best z among N independent ids under pure chance. With 10 ids it is about 1.5; with 100, about 2.5. Ids appear as a 6-character tag made by hashing the random id, so no part of the id itself is shown.
